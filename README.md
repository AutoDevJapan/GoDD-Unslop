# GoDD Unslop

日本語の原稿から、読み手が迷いそうな言葉を見つけるツールです。

> 今月の領収書は既定のフォルダーに保存してください。

この文で指摘するのは「既定」です。保存先が決まっているなら、「経費」など実際のフォルダー名を書くと伝わります。

原稿を `article.txt` という名前でUTF-8で保存し、次のコマンドを実行してください。

```sh
godd-unslop analyze article.txt
```

指摘した箇所と理由をJSONで返します。\
この点検は手元の端末で完結します。
