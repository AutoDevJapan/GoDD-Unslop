# GoDD Unslop

メールや案内文を送る前に、日本語の原稿を点検するツールです。

> 今月の領収書は既定のフォルダーに保存してください。

この文で引っかかるのは「既定」です。保存先が「経費」フォルダーなら、その名前を書けば伝わります。

UTF-8で保存した原稿のファイル名を指定してください。

```sh
godd-unslop analyze article.txt
```

指摘した箇所と理由をJSONで返します。\
このコマンドは原稿を外部に送りません。

[インストールと使い方](docs/user-guide.md)
