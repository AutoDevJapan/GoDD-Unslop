# 初期の評価

初版では新規の11テストにより、候補の検出、自然な対照文、引用・コード・URLの保護、数量変更の確認、UTF-8位置、入力上限、CLIとMCPの実通信を確認します。機械が意味の等価性を保証するテストではありません。

pilot-features.jsonには、今回取得した公開ページ4件、今回生成したAI例文4件、オーナーの短い指摘4件の数値があります。目的は特徴を取り出す処理の確認です。作者の制作方法が分からない公開ページはunknownとし、人間の文章という正解にしません。

群はテーマ、用途、長さが異なり、件数も少ないため、分類の精度や作者の確率、推敲の効果を示すデータではありません。人間らしさを判定するために、特定の平均文長へ文章を機械的に近づけることもしません。

数量・条件・否定・推量・責任の主語は、同じ語が残っていても意味が変わります。比較ツールは変更した範囲と確認候補を示すだけで、最後に原文と文脈を照合します。
