# 例文と入力ファイル

<a name="操作を試すサンプル"></a>

[Wiki「スライドとサンプル」](https://github.com/AutoDevJapan/GoDD-Unslop/wiki/スライドとサンプル)に、領収書の保存先を伝える例とコマンドを載せています。\
原文は [article.txt](article.txt)、書き手が保存先を確かめて直した文は [revised.txt](revised.txt) です。

資料を頼む相手の設定は [recipient.json](recipient.json)、依頼文は [recipient-request.json](recipient-request.json) です。\
架空の同僚を登録するときは、リポジトリの外に練習用DBを作ります。\
そのファイルの絶対パスを `GODD_UNSLOP_DB` に指定してから、[練習用DBを用意する手順](https://github.com/AutoDevJapan/GoDD-Unslop/wiki/相手に合わせて書く#相手の設定を保存する)に従ってください。
