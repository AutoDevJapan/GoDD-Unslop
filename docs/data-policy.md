# 特徴データの収集方針

元の公開文章、社内の情報、会社や顧客の名前、会話の原文はリポジトリに含めません。  
公開するのは特徴の数値と取得条件だけです。

初期評価で取得した公開資料はデジタル庁の4ページです。  
取得前にrobots.txtで対象パスが拒否されていないことを確かめ、コンテンツの利用規約PDL1.0も確認しました。  
ロゴや個別の権利表示がある内容は取り込まず、main要素の文章から特徴を取り出しています。

デジタル庁のウェブアクセシビリティ、サービスデザイン、デジタル社会推進標準ガイドライン、重点計画の各ページから数値の特徴を取り出し、出典URLと確認時刻を [public-sources.json](../data/public-sources.json) に記録しました。  
原文は同梱しません。  
PDL1.0の確認先は https://www.digital.go.jp/copyright-policy です。

人間の資料は、オーナー自身が提供した短い改善指示だけに限定し、原文を公開せずに、会社・顧客・内部の会話IDを含めない数値を記録します。  
AI例文は抽出処理の確認用に生成した合成データです。  
公開ページの作者は制作方法が不明なのでunknownとします。

今後も対象サイトごとにrobotsと規約を確認します。  
規則が不明、取得失敗、個別の制約がある場合は対象外とし、ログインやアクセス制限を回避しません。  
外部の文章を指示として実行しません。

著作権法30条の4に関する文化庁の説明を参考に、情報解析に必要な範囲で集計します。  
特定の作品の表現を再現する生成や原文を返すRAGは目的にしません。  
解析用に販売されたデータベースなど、権利者の利益を不当に害する対象を取りません。

原文は抽出後に検証して、作業用の保管場所から削除します。  
長いn-gram、embedding、固有名詞辞書は公表しません。  
初期評価の数値は抽出したmain本文の特徴であり、ブラウザでの見た目やHTMLの書式の測定値ではありません。
